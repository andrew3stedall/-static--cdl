# Player Notes

Create one note per official FPL player using:

`{Player Name} - {FPL ID}.md`

The FPL ID is mandatory because names, clubs and positions can change. Follow [[../00 Meta/Entity Model|Entity Model]].

Each note should link to the player's current [[../03 Teams/README|team]], [[../04 Positions/README|position]], cited [[../05 Sources/README|sources]], and every dated review or change that materially affected the player.
