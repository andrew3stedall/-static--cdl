# Cross-position review — overall ranks 1–30

## Changes since prior iteration

The position-by-position phase was complete, but it preserved position-specific ordering in fixed global slots. This run performed the first true cross-position insertion sort and adopted season-horizon injury weighting for Draft.

## Scope and method

Reviewed overall ranks 1–30 with ranks 31–35 as lower challengers. For every comparison, raw expected season FPL points came first. Minutes, role, penalties and set pieces, floor and ceiling followed. Positional replacement value was applied only at the final draft-first decision.

## Injury methodology adopted

- A player expected back within about one month receives only a small discount in a season-long Draft league.
- Five to ten weeks generally warrants a moderate discount.
- Multi-month, season-ending, recurrent or return-date-unknown cases receive substantial discounts.
- Expected role on return matters as much as the nominal return date.
- Premier Injuries was requested as a specialist source, but its injury table returned HTTP 403 to this run. The source remains documented for future accessible runs; no unsupported return date was adopted.
